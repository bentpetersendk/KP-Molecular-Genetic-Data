# Galaxy workflows for students

Workflows placed here are published with the course and may be shared with students.

**Data preprocessing of NGS reads:** there is deliberately **no** student workflow. In this exercise, students have to find an overrepresented sequence in the FastQC report themselves and enter it into Cutadapt. A workflow would either skip that step or reveal the sequence.

Rules for adding a workflow here:

- Add it only if running it does not skip a decision the exercise asks students to make, and it contains no answers.
- Use the pinned tool versions listed in the exercise.
- Describe the inputs and what the workflow does in a short section below.
- Teacher-only workflows (for example validation workflows that hard-code answers) belong in the private instructor repository, never here.
