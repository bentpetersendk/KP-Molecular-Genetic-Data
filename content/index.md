This site is the starting point for the KP – Molecular Genetic Data course. It collects the lectures, the hands-on exercise and the data.
The exercises run in your web browser on [Galaxy Europe](https://usegalaxy.eu), so you do not need to install any software.

## Before the first exercise

1. Create a free account on [Galaxy Europe](https://usegalaxy.eu/login/start) and log in.
2. Read [Getting started with Galaxy](galaxy/index.md) if you have not used Galaxy before.
3. Open the exercise from the [Exercises](exercises/index.md) page and follow it step by step.
   Write down your answers to the questions as you go.
